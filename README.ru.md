# Triggr VPN Bridge

Переключение выбранного системного VPN из **Triggr** без Shortcuts и открытия приложения.

[English](README.md) · [Сборка](docs/BUILDING.md) · [Проверка](docs/TESTING.md)

**Бета-версия.** Владелец устройства подтвердил работу прототипа на iPhone 12,
iOS 16.1.2, Dopamine 3, Triggr 2.1 и OneXray. Новый пакет и отдельная категория
действий в Triggr пока требуют проверки на устройстве. Другие VPN-клиенты не проверены.

## Установка и использование

Собрать пакет на Mac:

```sh
make check
make package
make install DEVICE=mobile@IPHONE_IP
```

После установки сделайте респринг. Зависимости `notifyutil` и ElleKit устанавливаются
через APT. Затем в Triggr выберите жест или событие → **VPN** → **Toggle VPN**,
**Turn VPN On** либо **Turn VPN Off**.

Если категория не появилась, выберите **Text & Commands → Run Command**:

```sh
/var/jb/usr/bin/triggr-vpn toggle
```

Вместо `toggle` можно указать `on` или `off`. `sudo` для действий не нужен.
Старые назначения с `notifyutil -p local.triggrvpnbridge.toggle` продолжают работать.

CCVPN не требуется; его можно оставить установленным. Мостик работает с системным
VPN, а не выбирает сервер или профиль внутри OneXray. Пакет предназначен для
rootless iOS 16. iOS 15, iOS 17+, RootHide и rootful не поддерживаются этим пакетом.

## Диагностика

```sh
triggr-vpn status
triggr-vpn toggle
# Подождите минимум секунду.
triggr-vpn status
```

| Код | Значение |
|---|---|
| 0 / нет значения | Статус не опубликован; проверьте установку и респринг |
| 1 | Мостик загрузился |
| 2 | Запрос обрабатывается |
| 3 | Повторный запрос пропущен защитой от частых срабатываний |
| 10–14 | Ошибка загрузки или вызова системного VPN API; подробнее в английском README |
| 100 / 101 | Отправлен запрос выключить / включить VPN |
| 200 / 201 | Система уже сообщала о выключенном / включённом VPN |

Это **последний диагностический статус**, а не текущее состояние туннеля или
доказательство, что мостик всё ещё загружен. Коды 100/101 не подтверждают успешное
подключение: проверьте значок VPN или настройки. Запросы в течение секунды после
переключения пропускаются. On Demand / Always On могут снова включать VPN.

## Удаление

```sh
sudo apt remove local.triggrvpnbridge
sudo sbreload
```

При Safe Mode удалите пакет через Sileo или SSH и сделайте респринг.

Мостик использует приватные API iOS. Локальные Darwin-уведомления не проверяют
отправителя: другие процессы на телефоне тоже могут вызвать эти действия.
Это не kill switch. Трафик, конфигурации и ключи VPN не читаются и не передаются.
